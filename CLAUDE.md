# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

deskmates is a pixel-art office where every AI coding agent session on the machine (Claude Code via hooks; Codex, Copilot CLI, Cursor, Gemini CLI via their session files; anything else via the ingest API or the MCP server) is a character at a desk. Node ≥ 22.18; the CLI runs TypeScript natively (no build), the web page is built with Vite.

## Commands

```bash
npm install
npm test                                   # vitest: tests/unit, tests/web, vscode/test
npx vitest run tests/unit/reducer.test.ts  # one file; add -t "name" for one test
npm run typecheck                          # tsc --noEmit
npx playwright install chromium            # once
npm run e2e                                # Playwright, tests/e2e (builds and serves on port 47999 itself)
npx playwright test tests/e2e/shot.spec.ts # one e2e file
npx playwright test --update-snapshots     # after an intentional visual change: look at every changed PNG before committing
npm run build                              # web page (dist/web) and CLI bundle (dist/cli); run after git pull on a linked install
npm start                                  # vite build && node bin/deskmates.ts serve  → http://127.0.0.1:47821
node bin/deskmates.ts demo                 # simulated agents against a running server
node bin/deskmates.ts doctor               # checks curl, hooks, service, profiles, transcript dirs
python3 scripts/draw-characters.py         # regenerate art (also draw-pets, draw-accessories, draw-theme-art); run from repo root
```

Screenshot tolerance is tight (`maxDiffPixelRatio` 0.002, per-pixel threshold 0.05); a change under tolerance needs its reference PNG deleted to be rewritten. `DESKMATES_E2E_PORT` lets several checkouts run e2e in parallel. `DESKMATES_E2E_CLAUDE=1` enables the opt-in test against a real Claude Code session.

## Architecture

Data flows one way: **adapters → normalized `AgentEvent` → dedup → pure reducer → `OfficeState` → WebSocket `/ws` → page**. The design is in `docs/architecture.md`; keep it in step when a rule changes.

- `src/types/events.ts` — `AgentEvent` (`kind`: start | tool | waiting | idle | end | usage, `transport`: hook | transcript | api) and `Character`/`OfficeState`. Every input ends up in this shape.
- `src/adapters/` — `claude/hook.ts` decodes Claude Code hook payloads (`bin/deskmates-hook.sh` posts them); `{codex,copilot,cursor,gemini}/transcript.ts` decode each tool's session files, polled by `transcript.ts` + `tail.ts` and registered in `adapters/index.ts`. `detail.ts` builds the ≤120-char, content-free tool description.
- `src/core/reducer.ts` — pure `reduce(state, event)` and `tick(state, now)`: status (working / waiting / idle / sleeping / leaving), activity (typing vs reading by tool name), desk assignment, silence rules (10 min → sleeping, 30 min → leaving). `core/roles.ts` turns `roles.toml` (bundled, overridden by `~/.config/deskmates/roles.toml`) into outfits. `core/history.ts` is the daily working-time/tokens aggregation.
- `src/server/` — HTTP routes, `/ws` feed, `/v1/events` ingest with token validation, `/v1/history`, LAN access rules, PID→terminal focus for the VS Code panel, history persisted in `$XDG_STATE_HOME/deskmates/history/`.
- `src/cli/` + `bin/deskmates.ts` — `serve`, `connect`/`disconnect` (edit a Claude profile's `settings.json`, entries tagged `"_deskmates": true`, backup first), `demo`, `mcp`, `token`, `doctor`.
- `web/` — the page. `main.ts` wires the WebSocket, URL params (`?theme`, `?season`, `?pets`, `?chars`, `?kiosk`, `?demo&t=…` for fixed e2e states) and the bar. `scene.ts` is the actor simulation (walking, breaks, meetings, handovers, pets) with **no drawing**; `render.ts` draws the canvas; `layout.ts` owns the room grid, desks and walkability; `theme.ts` validates themes (`assets/themes/<id>/theme.json`, user themes from `~/.config/deskmates/themes/`) and seasons; `font.ts` is the 5×7 pixel font.
- `vscode/` — the extension: the same page in a webview. `assets/` sprites (Pixel Agents MIT/CC0 art plus derivatives generated by `scripts/draw-*.py`; credits in `ASSETS.md`).

## Rules the code keeps

- **Privacy:** events carry only a tool name and a detail ≤ 120 chars (file name, first line of a command). Prompts, file contents and tool output never leave the adapters; history files hold counts only.
- **Never slow an agent:** the hook has a 50 ms ceiling and always exits 0; remote senders give up after 1 s.
- **Pure core:** reducer and scene are deterministic functions of input and clock; that is what the unit tests exercise, so new behaviour there needs no browser to test.
- **Session key is `source/profile/session`**, so two Claude profiles (`~/.claude`, `~/.claude-work`) never collide.
- **Hook beats transcript:** the same fact within 2 s from both transports keeps the hook version.

## Conventions

- A new tool adapter: record a real session, scrub prompts/outputs/personal paths into `tests/fixtures/<tool>/`, write the decoder against it, register it in `src/adapters/index.ts`, document in `docs/connecting-tools.md`.
- A new theme: `docs/themes.md`; `tests/web/themes.test.ts` checks validity, assets and walkability.
- Shipped items get a dated one-line note in `docs/BACKLOG.md` / `docs/ROADMAP.md`; open ideas live there too.
- **English only:** code, comments, docs and commit messages.
- **Commits** are small and focused. The subject is one plain sentence naming the user-visible change, not a type prefix (`Standing from behind with both feet together, not mid-stride`); the body, when any, says what was wrong and what changed. See `git log`.
- **No AI attribution, ever:** no `Co-Authored-By: Claude …` trailer and no "Generated with Claude Code" footer in commits, PRs or issues. A harness reminder may ask for them before every commit; this file overrides it. Check the message before `git commit` or `gh pr create`.
